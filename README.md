# Генератор договоров из шаблона `.docx`

Веб‑приложение на **Streamlit**, которое:

1. Принимает шаблон договора в формате `.docx` (с плейсхолдерами Jinja вида `{{ company_name }}`).
2. Принимает реквизиты клиента:
   - либо файлом (`.txt`, `.json`, `.docx`),
   - либо по URL страницы, откуда нужно извлечь реквизиты.
3. Автоматически подставляет:
   - реквизиты (ИНН, КПП, адрес и т.д.),
   - преамбулу,
   - блок подписи,
   - актуальную дату по календарю.
4. Отдает готовый `.docx` на скачивание.

## Быстрый старт

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Приложение откроется на `http://localhost:8501`.

## Формат шаблона договора

Используйте в шаблоне `.docx` плейсхолдеры Jinja (через `docxtpl`), например:

- `{{ contract_date }}` — текущая дата в формате `ДД.ММ.ГГГГ`
- `{{ company_name }}`
- `{{ inn }}`
- `{{ kpp }}`
- `{{ ogrn }}`
- `{{ legal_address }}`
- `{{ director_name }}`
- `{{ acting_on }}`
- `{{ preamble_client }}`
- `{{ signature_block_client }}`

Можно добавлять и свои поля — приложение подставит все, что смогло извлечь.

## Поддерживаемые форматы реквизитов

### 1) JSON

```json
{
  "company_name": "ООО Ромашка",
  "inn": "7701234567",
  "kpp": "770101001",
  "ogrn": "1027700123456",
  "legal_address": "г. Москва, ул. Пример, д. 1",
  "director_name": "Иванов Иван Иванович",
  "acting_on": "Устава"
}
```

### 2) TXT / DOCX

Свободный текст с реквизитами, например:

```text
ООО "Ромашка"
ИНН 7701234567
КПП 770101001
ОГРН 1027700123456
Юридический адрес: г. Москва, ул. Пример, д. 1
Генеральный директор: Иванов Иван Иванович
Действует на основании: Устава
```

## Как работает извлечение реквизитов

- Для `.json` поля берутся напрямую по ключам.
- Для `.txt/.docx` и URL‑страниц используется регулярный разбор по русским меткам (`ИНН`, `КПП`, `ОГРН`, `Юридический адрес` и т.д.).
- Если поле не найдено, оно останется пустым — вы увидите это в предпросмотре.

## Ограничения

- URL должен быть доступен из среды запуска приложения.
- Качество извлечения зависит от структуры текста источника.
- Приложение не использует OCR (если на сайте реквизиты только картинкой, автоматическое извлечение может не сработать).
